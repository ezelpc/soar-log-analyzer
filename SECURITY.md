# Security Policy

This repository is a defensive SOC / detection-engineering lab intended for authorized environments.

## Reporting
Report suspected vulnerabilities privately to the repository owner before public disclosure. Never publish credentials, tokens, personal data, or production log contents in an issue.

## Defensive scope
The project is designed for log analysis, detection engineering, incident triage, evidence preservation, and authorized security testing. Do not use it to access systems without permission.

## Data handling
Use synthetic or sanitized logs in demonstrations. Treat generated incident reports and telemetry as potentially sensitive artifacts.
